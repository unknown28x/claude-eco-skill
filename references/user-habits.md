# What the user can change

Ranked by gain. The first three do most of the work.

1. **One session per topic, and short.** Topic done → ask for a "handoff" and open a fresh
   session. Never reopen an old giant session for "just one thing".
2. **Mid-tier model by default.** The largest model for a single hard problem, in a short
   dedicated session. Choose the model before the first message, not along the way.
3. **No extended-context (1M) variant** for everyday work.
4. **A long break = a fresh session** if the session was already long.
5. **One complete message instead of five small ones.** Each message triggers a full re-read.
   Give at once: the goal, the file or page concerned, the example, the finish check.
6. **Paste the error, not the whole log.** Give a file path rather than its content.
7. **Interrupt early** when it heads the wrong way, then correct in one sentence.
8. **Connectors**: enable only those the day's topic needs.
9. **Once a week**: `python ~/.claude/skills/eco/scripts/audit.py --days 7`.
   Read two sections: "BY MODEL" and "HEAVIEST SESSIONS".
